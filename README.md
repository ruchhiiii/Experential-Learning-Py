Password Strength Analyzer Using Hashing
Phase 2 implementation
## Objectives

- To evaluate password strength.
- To identify weak passwords.
- To provide password security suggestions.
- To demonstrate SHA-256 hashing using Python.
- To develop an interactive web application.
## Technologies Used

- Python
- hashlib
- SHA-256 Hashing
- Streamlit
- GitHub
## Features

- Password strength evaluation.
- Weak, Medium, and Strong classification.
- Warnings for weak passwords.
- Suggestions for improving password security.
- Visual strength indicator.
- SHA-256 hash generation.
- Interactive web interface.
